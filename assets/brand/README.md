# Brand assets

## Masters (PNG)
- `logo-transparent.png` — header + favicon
- `icon-square.png` — PWA / apple-touch
- `icon-rounded.png` — rounded preview

## Editable SVG
Edit files in `source/`, then:

```bash
npm run icons -- --from-svg
```

Resize only from current PNG masters:

```bash
npm run icons
```
